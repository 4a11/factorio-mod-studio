# Factorio Mod Studio

[English](README.md) · [Русский](README.ru.md) · [Deutsch](README.de.md) · [简体中文](README.zh-CN.md) · **Українська** · [Polski](README.pl.md) · [Français](README.fr.md) · [Español](README.es.md)

**Локальна майстерня для авторів модів [Factorio](https://factorio.com).** Створіть мод, знайдіть його помилки раніше за гру,
перекладіть його, зберіть чистий реліз і запустіть з ізольованим набором модів — з командного рядка або зі сторінки в браузері.
Усе працює на вашому комп'ютері, поруч зі звичним редактором коду.

> **Рання версія (0.1).** Логіку покрито тестами; запуск справжньої гри (`run`, `smoke`) працює з Factorio 2.1 під Windows.
> Інші версії та системи ще не перевірено. Відгуки та повідомлення про помилки дуже вітаються.
> Неофіційний проєкт спільноти, не пов'язаний з Wube Software. «Factorio» — торговельна марка Wube Software Ltd.
>
> Це переклад вступної частини. Докладна документація — [англійською](README.md#documentation); у разі розбіжностей правильним є англійський README.

## Що вміє

- **Мод за секунди.** Шаблони (порожній, предмет + рецепт, сутність, скрипт часу виконання) для Factorio 2.0 і 2.1 (усі, крім сутності, — і для 1.1), які одразу проходять усі перевірки.
- **Помилки — раніше за гру.** `info.json`, changelog, мініатюра, биті шляхи `__mod__/` і `require`, відсутні чи зламані переклади — усе з файлом і рядком.
- **Погляд усередину будь-якого мода.** Студія в браузері: дерево файлів, редактор Lua з перевірками на льоту, прототипи та рецепти мода, його графіка і звуки, а також файли, які ніхто не використовує.
- **Зручний переклад.** Редактор «оригінал — переклад» з прогресом за мовами, перевіркою плейсхолдерів і підказками з ваших попередніх перекладів.
- **Чистий реліз.** `NAME_VERSION.zip` з правильною структурою тек, збирається, лише якщо мод проходить перевірку.
- **Тести, не чіпаючи вашу гру.** Запуск Factorio або headless smoke-тест з ізольованим набором модів для кожного профілю; звичайна тека модів не зачіпається. Працює в CI.
- **Логи читаються швидше.** Лог Factorio стискається до помилок і попереджень, дублікати об'єднуються, у кожної — файл, рядок і підказка.

## Дорожня карта

Де проєкт зараз і що далі. Версії — це цілі, а не терміни; порядок визначають відгуки, тож
[відкрийте issue](https://github.com/4a11/factorio-mod-studio/issues), якщо вам важливий якийсь пункт (або його тут бракує).

**0.1: зараз.** Командний рядок (`new`, `validate`, `pack`, `prepare` / `run`, `smoke`, `log`, `factorio`) і студія в браузері
(Огляд, Файли, Прототипи, Ресурси, Локалізація, Проблеми, Збирання) 8 мовами інтерфейсу.

**0.2: перевірено на справжній грі**
- [ ] `run` і `smoke` перевірено на Factorio 1.1, 2.0 і 2.1 під Windows, Linux і macOS, зокрема на headless-сервері; *2.1 під Windows працює*
- [ ] після запуску чи smoke-тесту читається й `factorio-current.log`, його помилки видно у вкладках «Проблеми» та «Вивід»
- [ ] прототипи, які створюють шаблони (сутність, скрипт часу виконання), завантажено в грі, а не лише написано за документацією
- [ ] встановлення одним рядком: інструмент опубліковано в NuGet (`dotnet tool install -g FactorioModStudio.Cli`), клонувати не потрібно
- [ ] версії Factorio встановлює сама студія: `fmstudio factorio install 2.0` завантажує безплатний headless-сервер (Linux, WSL, CI), де його знайде `smoke`, зокрема з вкладки «Збирання»; *зроблено, на справжньому завантаженні ще не перевірено*

**0.3: решта вкладок**
- [ ] «Проблеми» в новому стилі: групування за файлами й правилами, безпечні швидкі виправлення (додати відсутній ключ перекладу, виправити регістр літер у шляху)
- [ ] «Збирання»: вибір профілю, додаткових модів і збереження; історія запусків для порівняння
- [ ] іконки інгредієнтів і результатів з базової гри або залежностей
- [ ] залежності одним поглядом: обов'язкові, необов'язкові, несумісні та які з них є в `modsSource`

**0.4: випуск релізів**
- [ ] підвищення версії та запис у changelog за один крок (`fmstudio bump patch|minor|major`)
- [ ] завантаження на мод-портал Factorio (за бажанням, з вашим власним API-ключем)
- [ ] готовий workflow для GitHub Actions (`fmstudio init --ci`): перевірка, збирання і smoke-тест на кожен push

**Пізніше**
- підсумкові прототипи через `--dump-data`: «який мод змінив цей предмет і як?»
- запуск тестів, написаних для [FactorioTest](https://mods.factorio.com/mod/factorio-test), просто зі студії
- розширення для редактора (VS Code) поверх того самого API

## Навіщо

Редагування Lua, налагодження та юніт-тести вже добре закриті (наприклад, *Factorio Modding Tool Kit* для VS Code і *FactorioTest*).
Виснажливою лишається «склейка» навколо них: правильний zip для релізу, відтворюваний набір модів для запуску, єдина справжня
помилка в стіні логу, переклади, що розходяться між собою. Factorio Mod Studio бере цю склейку на себе.

## Швидкий старт

Потрібен [.NET 8 SDK](https://dotnet.microsoft.com/download).

```sh
# 1. Встановити інструмент `fmstudio` (один раз)
git clone https://github.com/4a11/factorio-mod-studio
cd factorio-mod-studio
dotnet pack src/FactorioModStudio.Cli -c Release -o ./nupkg
dotnet tool install --global FactorioModStudio.Cli --add-source ./nupkg

# 2. Створити мод у будь-якій зручній теці та відкрити студію
cd ~/factorio-dev
fmstudio new my-mod --template item-recipe   # готовий до запуску мод у ./mods/my-mod
fmstudio ui                                  # усі моди з ./mods — у браузері
```

Типовий цикл — кнопки вгорі кожного мода в браузері або те саме в терміналі з теки мода:

```sh
cd mods/my-mod
fmstudio validate      # що не так, з файлом і рядком
fmstudio pack          # dist/my-mod_0.1.0.zip
fmstudio smoke         # завантажити headless на 600 тиків; падає за будь-якої помилки
fmstudio run           # запустити Factorio лише з цим модом і його залежностями
```

Factorio знаходиться автоматично (звичайні теки встановлення, `FACTORIO_PATH` або встановлення, додані в інтерфейсі); використовується
версія, що збігається з `factorio_version` мода.
