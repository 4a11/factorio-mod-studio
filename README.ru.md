# Factorio Mod Studio

[English](README.md) · **Русский** · [Deutsch](README.de.md) · [简体中文](README.zh-CN.md) · [Українська](README.uk.md) · [Polski](README.pl.md) · [Français](README.fr.md) · [Español](README.es.md)

**Локальная мастерская для авторов модов [Factorio](https://factorio.com).** Создайте мод, поймайте его ошибки раньше игры,
переведите его, соберите чистый релиз и запустите с изолированным набором модов — из командной строки или со страницы в
браузере. Всё работает на вашем компьютере, рядом с привычным редактором кода.

> **Ранняя версия (0.1).** Логика покрыта тестами; запуск настоящей игры (`run`, `smoke`) работает с Factorio 2.1 под Windows.
> Другие версии и системы ещё не проверены. Отзывы и сообщения об ошибках очень приветствуются.
> Неофициальный проект сообщества, не связан с Wube Software. «Factorio» — товарный знак Wube Software Ltd.

## Что умеет

- **Мод за секунды.** Шаблоны (пустой, предмет + рецепт, сущность, скрипт времени выполнения) для Factorio 2.0 и 2.1 (все, кроме сущности, — и для 1.1), которые сразу проходят все проверки.
- **Ошибки — раньше игры.** `info.json`, changelog, миниатюра, битые пути `__mod__/` и `require`, отсутствующие или сломанные переводы — всё с файлом и строкой.
- **Взгляд внутрь любого мода.** Студия в браузере: дерево файлов, редактор Lua с проверками на лету, прототипы и рецепты мода, его графика и звуки, а также файлы, которые никто не использует.
- **Удобный перевод.** Редактор «оригинал — перевод» с прогрессом по языкам, проверкой плейсхолдеров и подсказками из ваших прежних переводов.
- **Чистый релиз.** `NAME_VERSION.zip` с правильной структурой папок, собирается, только если мод проходит проверку.
- **Тесты, не трогая вашу игру.** Запуск Factorio или headless smoke-тест с изолированным набором модов для каждого профиля; обычная папка модов не затрагивается. Работает в CI.
- **Логи читаются быстрее.** Лог Factorio сжимается до ошибок и предупреждений, дубликаты объединяются, у каждой — файл, строка и подсказка.

## Зачем

Редактирование Lua, отладка и юнит-тесты уже хорошо закрыты (например, *Factorio Modding Tool Kit* для VS Code и *FactorioTest*).
Утомительной остаётся «склейка» вокруг них: правильный zip для релиза, воспроизводимый набор модов для запуска, единственная
настоящая ошибка в стене лога, переводы, которые расходятся друг с другом. Factorio Mod Studio берёт эту склейку на себя.

## Быстрый старт

**Проще всего:** скачайте архив для своей системы со страницы [Releases](https://github.com/4a11/factorio-mod-studio/releases/latest) и распакуйте; .NET не нужен. В Windows
дважды щёлкните `fmstudio.exe`, и студия откроется в браузере; в других системах запустите `./fmstudio ui`.

**Как инструмент .NET** (нужен [.NET 8 SDK](https://dotnet.microsoft.com/download)):

```sh
# 1. Установить инструмент `fmstudio` (один раз)
git clone https://github.com/4a11/factorio-mod-studio
cd factorio-mod-studio
dotnet pack src/FactorioModStudio.Cli -c Release -o ./nupkg
dotnet tool install --global FactorioModStudio.Cli --add-source ./nupkg

# 2. Создать мод в любой удобной папке и открыть студию
cd ~/factorio-dev
fmstudio new my-mod --template item-recipe   # готовый к запуску мод в ./mods/my-mod
fmstudio ui                                  # все моды из ./mods — в браузере
```

Типичный цикл — кнопки вверху каждого мода в браузере или то же самое в терминале из папки мода:

```sh
cd mods/my-mod
fmstudio validate      # что не так, с файлом и строкой
fmstudio pack          # dist/my-mod_0.1.0.zip
fmstudio smoke         # загрузить headless на 600 тиков; падает при любой ошибке
fmstudio run           # запустить Factorio только с этим модом и его зависимостями
```

Factorio находится автоматически (обычные папки установки, `FACTORIO_PATH` или установки, добавленные в интерфейсе); используется
версия, совпадающая с `factorio_version` мода.
